
# ムシキン(いつやるかは未定)

## ボイステキストバグ

アドレス `0x021D1046`

声の高さと速さは、料理ナビと同じく、上のアドレスに `0x8CE6` を引いた、`0x021C8360`


- ボイステキストデータ: `0x021D1046`
- 詳細データ: `0x021CAEA0` (-61A6)
- ボイス設定データ: `0x021C8360` (-8ce6)


構造は料理ナビと大体同じだが、特殊記法が使われている。

テキストの一部に

```
#V120\n#Z\n#S75\n

#B+500\n#A0\n#P0
(+: 0x2b, 0: 0x2d)
```

といった感じに`#<英字>`のprefixが付くことがある。

これはボイスの設定をしているみたい

- `#S`はスピード(値が大きいほど遅い)
- `#V`はボリューム(値が小さいほど声が小さい)
- `#P+<値>`はピッチ
- 主人公ボイス
    - `#B5250\n#S90\n#X103\n#I500\n#J20\n#S75`
- `#B5250` (主人公ボイスにて)
- `#X103` (主人公ボイスにて)
- `#I1000`: (冒頭のワルキングボイスにて) ?
- `#J70`: (冒頭のワルキングボイスにて)リバーブ?

## 所持カード

`0x21C3900`あたりから

- `21C3935`がムシno01のギラファ
    - `396A`でプラティオドン(no.54)が来た後、`396B`でムシキング(no.00)となり、その次は限定カード
    - `3971`が最後のアダーネプチューンで次の2byte(`72,73`)は未使用
- `21C3974`がわざno01のガンガンスマッシュ
    - `39A7`でばいがえし(no.52)が来た後、`39A8`でキングトルネードスロー(no.00)となり、その後はスーパー技が続く
    - 最後は`39BA`のスーパーアクシズスピン

## 主人公名

`0x021C3906` (SJIS)

あと `21C49B8`にもある

文字コードはsjis(他のテキストも同様)

```
"ひなみ": 82D0 82C8 82DD
"レイカ": 838C 8343 834A
"アキコ": 8341 834c 8352
```


### 主人公名のイントネーションについて

- レイカにすると、「レイカじゃないか」や「レイカさん」などのときに、レが一番低くてカに向けて高くなっていく、つまり想定とは逆のイントネーションになってしまう。
- これを根本的に解決する方法は見つかっていない。
- しかし、ROMないのボイスデータの`*n`部分を、`レ’ーカ`とし、その部分の他の`’`の箇所を削除、または`／`を名前の直後に配置することで、イントネーションを強引に解決することはできる。

一応以下のアドレスに設定した名前がカタカナになって反映されるが、直接いじっても効果が見られなかった

```
`0x21C4F6C` <= ここに反映される時点ではもう遅い

ほかにも以下の箇所があったが、いじっても反応ナシ
    0x021C49B8
    0x021C4F80
    0x021C5199
    0x021C6E43
    0x021D3476
    0x025C49B8
    0x025C4F80
    0x025C5199
    0x025C6E43
    0x025D3476
    0x027E34E6
```

## ROMのボイス情報

ボイスは全部カタカナ。
アクセント位置を指定する記号は途中に挿入されているので、検索は少し大変。

`00`で各データを区切る

例:

`2F50B0`

`’`: 日本語入力でspace+7をそのまま変換せずにEnterした文字。
