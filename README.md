
# BizHawk cheats

エミュレータ BizHawk でcheatingを行うための(主にlua関連の)ドキュメント等の保管庫。

(luaライブラリは現在、DSソフト用に特化している。他機種の場合だとメモリ読み書きなどで不具合が発生する可能性アリ。)

## 導入方法

※Windows環境を想定する。

1. VSCode, BizHawk(バージョンは2.11.1を想定)をインストール
1. VSCode上で、ibiz拡張機能(`/.sub_projects/vscode-bizhawk-server/vsix`上のもの)とlua言語サポート拡張機能(`sumneko.lua`)をインストール
1. `.lib/set_env.ps1`を参考に、ユーザー環境変数を適切に設定→変更を反映させるために一旦再起動する
    - スクリプトを直接実行する場合はExecutionPolicyに注意
1. 本リポジトリのrootディレクトリにあたる場所(.vscodeや.libがある場所)をVSCodeで開く(そのディレクトリ直下で`code .`とするなどして)
1. `<任意のファイル名>.ibiz`ファイルを作成して開く
1. ステータスバーにある`BizHawk inactive`ボタンをクリックしてサーバを起動(ポート番号はデフォルトで8099。設定で変更可)
    - サーバを閉じるのも同じボタンで行う
1. BizHawkアプリを以下のオプションで起動:
    ```
    EmuHawk.exe --luaconsole --socket_port=8099 --socket_ip=127.0.0.1
    ```
    - この時点でサーバを起動していないと、エラーウィンドウが表示されてBizHawkが起動できないので注意
1. 自動で開かれたスクリプトマネージャーウィンドウから`repl.lua`を開く
1. READYの文字が印字されたら、Ibiz notebookからコマンドを送信していく
    - なお、しばらく送信していない状態でいると、次の送信に数秒～十数秒程度の遅延が発生するが、問題なく使える
    - **BizHawkアプリを閉じる前にサーバを閉じるとアプリがフリーズするので注意**
    - luaの言語サポートを使用するには、ノートブックのどこかに定義ファイルの中身を置く必要がある。コマンドパレットから「テンプレートをノートブックの最上段に挿入」などと書かれたコマンドと実行するとよい
