
# 音量調整

- https://qiita.com/mml/items/c28d69ab889eb36dd522
- https://note.com/tennoma/n/n89d7d4f00769

```
音量を半分にする
ffmpeg -i input.mp4 -af "volume=0.5" -c:v copy output.mp4
```

- 音量を変えずに動画を作ってエンコードし、仕上がったものを丸ごと音量調整するのがよさそう。


# DSの縦画面と横画面を分割する

- size: 1024(幅)x1536(高さ)
- 分割して結合すると、2048x768になるはず

```
ffmpeg -i in.mp4 -vf "crop=1024:768:0:0" out-u.mp4

ffmpeg -i in.mp4 -vf "crop=1024:768:0:768" -an out-b.mp4

(,scale=1024:768はつけなくてよい)
(-anはミュート化)
ffmpeg -i input.mp4 -vf "crop=幅:高さ:X座標:Y座標,scale=変更後の幅:変更後の高さ" -c:a copy output.mp4

crop=w:h:x:y: 画面を切り抜くフィルタです。w: 切り抜く幅h: 切り抜く高さx: 元動画の左上を原点（0）としたときの切り抜き開始位置（X軸）y: 元動画の左上を原点（0）としたときの切り抜き開始位置（Y軸）
```

# DSの縦画面と横画面を、左右に配置する

```
ffmpeg -i in.mp4 -filter_complex "[0:v]crop=iw:ih/2:0:0[top]; [0:v]crop=iw:ih/2:0:ih/2[bottom]; [top][bottom]hstack=inputs=2[v]" -map "[v]" -map 0:a? out.mp4
```

> ffmpegにて、縦長の動画に対し、高さ半分の位置で2分割し、それらを横方向に連結させるような編集を実現するには、どのようにすればよいでしょうか？

FFmpeg のフィルタを使えば実現できます。

例えば、入力が **1080×1920 の縦長動画**だとして、

* 上半分（0～959px）
* 下半分（960～1919px）

に分割し、それらを左右に並べるなら次のようになります。

```bash
ffmpeg -i input.mp4 \
-filter_complex \
"[0:v]crop=iw:ih/2:0:0[top]; \
 [0:v]crop=iw:ih/2:0:ih/2[bottom]; \
 [top][bottom]hstack=inputs=2[v]" \
-map "[v]" -map 0:a? \
-c:v libx264 -crf 18 -preset medium \
output.mp4
```

### 処理内容

1. 上半分を切り出し

```text
crop=iw:ih/2:0:0
```

* 幅: `iw`
* 高さ: `ih/2`
* x: `0`
* y: `0`

2. 下半分を切り出し

```text
crop=iw:ih/2:0:ih/2
```

3. 横方向に結合

```text
hstack=inputs=2
```

元動画

```text
+------+------+
| 上側 | 下側 |
|      |      |
+------+------+
```

### 左右の順番を逆にしたい場合

```bash
[bottom][top]hstack=inputs=2[v]
```

---

### 元動画が 9:16 の場合

例えば 1080×1920 なら、

```text
1080×1920
 ↓
上半分: 1080×960
下半分: 1080×960
 ↓
横結合
2160×960
```

となります。

---

もし「上半分と下半分を左右に並べた後、さらに 16:9 の横動画サイズ（1920×1080 など）に収めたい」のであれば、`scale` や `pad` を組み合わせたフィルタ例も示せます。
